# Figma AI Prompt – Modern E-Commerce Website (Snapdeal Redesign)

Design a modern, premium, responsive e-commerce website for **Snapdeal** with a clean, minimal, and user-friendly interface inspired by the usability of Amazon and Flipkart, while keeping a unique visual identity. Use Material Design 3 principles with a modern card-based layout.
